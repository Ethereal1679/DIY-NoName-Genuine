# 多人联机服务器

此目录提供与游戏内“联机”模式兼容的 WebSocket 大厅服务器，支持：

- 在线大厅与房间列表
- 创建、加入和退出房间
- 房主与玩家之间的游戏消息转发
- 昵称、头像、在线状态和约战信息同步
- 心跳检测与断线通知

## 本地运行

在项目根目录启动游戏网页：

    py -m http.server 8080

另开一个 PowerShell 窗口启动联机服务器：

    cd server
    pnpm install
    pnpm dev -- --port 8082 --host 0.0.0.0

浏览器打开 http://127.0.0.1:8080，进入“联机”模式。默认大厅地址会根据网页地址自动设置为“当前主机:8082”。

局域网玩家应通过房主的局域网地址打开网页，例如 http://192.168.1.10:8080；游戏会自动连接 ws://192.168.1.10:8082。

## 构建和测试

    pnpm run build
    pnpm test

协议测试会自动验证大厅、建房、加入房间、双向消息转发和断线通知。
